# Cajumel | Avaliador de PDVs

Aplicação estática para avaliação de pontos de venda. Abra o site pelo endereço do GitHub Pages.

As avaliações ficam no localStorage de cada navegador. Não há autenticação, sincronização ou envio de avaliações para o GitHub. Use Exportar JSON para backups.

Publicação: em Settings > Pages, selecione Deploy from a branch, branch main, pasta / (root). Ative Enforce HTTPS quando disponível.
